# Ayla

A desktop companion that walks me through my work day. I built it because I can't rely on willpower alone, I need something that shows up and nudges me.

<!-- ![Ayla](ayla.png) -->

**What it does**
- Morning briefing to start the day
- Focus tracking while I work
- End-of-day review of what actually got done
- Plus version: AI goal breakdown, auto-launching my work apps, Google Calendar integration

**Built with:** Electron, TypeScript, Node.js
**Status:** Plus version deployed, I use it daily. Premium is next.

*Source code is private for now.*
